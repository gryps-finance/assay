Assay · measured priors for Nansen Smart Money

What Nansen's smart-money flows were worth, measured.

Nansen tells you what a labelled cohort did. Assay measured what that was worth: 12,781 Nansen API calls, 20 tokens, 18 months, six cohorts, three horizons, every claim paired with a drift-matched control, and the whole plan sealed before the first call. None of the eighteen cleared the bar. The same instrument finds a planted edge when there is one; the other page shows it doing so.

Run it · serve it · why

    

      

        
Read it yourself, no API key

        
git clone https://github.com/gryps-finance/assay, then node src/cli.mjs leaderboard
        prints these eighteen rows from ledger/study, and node src/cli.mjs audit prints the
        window audit. Zero dependencies, Node 18+.

      

      

        
Put it in front of an agent

        
node src/cli.mjs now joins yesterday's Nansen flows to these priors and says trade, hold, skip or
        refuse for each. node src/mcp-server.mjs serves the same to Claude or any MCP client, with live
        Hyperliquid positioning beside it.

      

      

        
Why a null is worth shipping

        
An agent handed a flow signal treats confidence as edge. On these flows, an agent that trades every signal expects
        to lose money at every cost from 0 to 200 bps; one that checks the prior first declines them all and loses nothing.

      

    

    

      

        
Run it yourself, no API key

        
node test/make-fixtures.mjs fixtures then node src/run-tournament.mjs --replay fixtures/.
        The generator is seeded and byte-for-byte deterministic, so it ships instead of the 35 MB it produces.
        A result nobody else can reproduce is a claim, not a finding.

      

      

        
Serve it to an agent

        
node src/mcp-server.mjs serves four MCP tools, zero dependencies. It refuses to hand
        back a signal for a pair it has never assayed, because an agent given an uncalibrated number treats
        confidence as edge.

      

      

        
Why this is worth something

        
Nansen's labels are the moat. What has never been published is what they are worth in basis
        points. The priced-out list is a product roadmap, because every line on it converts the
        moment execution gets cheaper.
